Héberger son propre salon¶

Le salon est le petit service qui aide les joueurs d'un jeu à se trouver. Par défaut, chaque jeu fait avec WorldMint utilise celui de WorldMint, partagé par tous les jeux. Cette page explique quand en héberger un à soi, et comment.

En avez-vous besoin ?¶

Le plus souvent, non. Le salon de WorldMint suffit à la plupart des jeux : chaque jeu a son identifiant, et ses joueurs ne voient que ses serveurs. Il n'y a rien à installer ni à payer.

Héberger votre propre salon a du sens si vous voulez :

  • l'indépendance : votre jeu ne dépend plus d'un service que vous ne tenez pas ;
  • une région proche de vos joueurs : un serveur en Amérique ou en Asie pour un public de là-bas (c'est surtout le relais qui y gagne) ;
  • votre propre relais : la bande passante des parties relayées est la vôtre, vous la surveillez et l'agrandissez à votre guise.

Ce que fait le salon¶

  • La liste des serveurs publics de votre jeu (onglet Liste du menu « Rejoindre une partie »).
  • Les codes courts, comme K7P-2QMX (onglet Code) : faciles à dicter à un ami.
  • Le perçage des box : il sert de messager le temps que deux jeux se connectent l'un à l'autre, sans ouvrir de port.
  • Le relais (TURN) : quand aucune box ne se laisse percer, la partie passe par lui. Elle reste chiffrée de bout en bout : le relais ne peut pas la lire.

La partie elle-même ne passe jamais par le salon, sauf par le relais. Le salon ne demande aucun compte ; il voit l'adresse IP de ceux qui lui parlent et l'oublie vite (voir CONFIDENTIALITE.md dans le kit).

Ce que ça coûte¶

Un petit serveur Linux loué (un « VPS ») : environ 5 € par mois chez un hébergeur comme OVHcloud, Scaleway, Netcup ou Hetzner, la plus petite offre suffit. Il faut aussi un nom de domaine (environ 10 € par an), ou un nom gratuit chez duckdns.org pour essayer. Comptez une heure la première fois.

Les étapes¶

Le kit est livré avec l'éditeur : dans le dossier de WorldMint, outils\salon (par défaut %LOCALAPPDATA%\Programs\WorldMint\outils\salon). Il contient le programme du salon, son script d'installation et sa notice, LISEZMOI.md, qui détaille chaque étape :

  1. louer le serveur (Ubuntu 24.04 ou Debian 12) ;
  2. choisir un nom pour le salon, par exemple salon.mon-jeu.fr ;
  3. faire pointer ce nom vers l'adresse du serveur ;
  4. copier le dossier sur le serveur et lancer le script : il installe tout (le salon, le HTTPS et son certificat gratuit, le relais, le pare-feu) et finit par « Le service répond ».

Le champ à remplir dans l'éditeur¶

Ne sélectionnez rien : les Propriétés montrent les réglages du jeu (le panneau Réglages du jeu aussi). Dans la section Multijoueur (« Jeu à plusieurs » allumé) :

  1. tapez l'adresse de votre salon dans Service de salon, par exemple https://salon.mon-jeu.fr ;
  2. cliquez sur Tester le salon : l'éditeur demande au salon s'il répond, sans se bloquer. Il dit « Le salon répond (2 serveurs en ligne) », « Pas de réponse : vérifiez l'adresse » ou « Ce n'est pas un salon WorldMint » ;
  3. exportez le jeu (et son serveur dédié) : ils utiliseront votre salon.

Champ vide : le salon de WorldMint (l'indication grisée dit « Celui de WorldMint »). L'adresse doit commencer par https://. Pour un essai sur votre PC seulement, lancez python salon.py --ecoute 127.0.0.1 --port 8470 dans le dossier du kit, puis mettez http://127.0.0.1:8470 dans le champ (le http n'est accepté que vers ce PC). Chaque changement s'annule avec Ctrl+Z, et l'agent peut aussi le régler si vous lui donnez l'adresse.

Et s'il tombe ?¶

Si votre salon ne répond plus, les onglets Liste et Code le disent, et le perçage des box ne se fait plus. Rejoindre une partie par son adresse marche toujours : la partie ne passe pas par le salon. Relancez le script d'installation sur le serveur ; il peut être lancé autant de fois qu'il le faut, sans risque.
