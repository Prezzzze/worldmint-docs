Traduire son jeu¶

Vous écrivez votre jeu dans votre langue. Pour le proposer aussi en anglais, en espagnol ou en allemand, il suffit d'ajouter ces langues et de remplir leurs traductions : vous-même, case par case, ou l'agent, en un clic. Aucun code n'est nécessaire.

Choisir les langues du jeu¶

Sans rien sélectionner dans la scène, les propriétés montrent les réglages du jeu. Dans la section Langues du jeu :

  • Langue d'origine : la langue dans laquelle vous écrivez les répliques, les messages et le titre. C'est d'ordinaire la vôtre.
  • Ajouter une langue : chaque langue ajoutée est proposée aux joueurs. La croix à côté d'une langue la retire ; ses traductions restent dans le projet, et la rajouter les retrouve.

L'agent peut aussi le faire : « mets mon jeu en anglais et en espagnol ».

Quelle langue voit le joueur¶

Au lancement, le jeu choisit la langue du joueur :

  1. celle qu'il a choisie la fois précédente dans les options du menu ;
  2. sinon celle de Windows, si le jeu la propose (un Windows en anglais du Canada donne l'anglais) ;
  3. sinon la langue d'origine.

Avec le système Menu, le bouton Options montre une ligne Langue : chaque clic passe à la langue suivante, et tout ce qui est à l'écran se met à jour. Le jeu s'en souvient pour les parties suivantes.

Un texte qui n'a pas de traduction s'affiche dans la langue d'origine : un jeu à moitié traduit reste jouable.

La fenêtre Traductions¶

Le menu Jeu > Traductions (ou le bouton Traductions... des langues du jeu) ouvre la liste de tous les textes que voit le joueur, trouvés automatiquement :

  • les textes des systèmes : les répliques et les réponses du Dialogue, le nom affiché d'un personnage, les messages et le texte de fin du Déclencheur, le titre de l'écran titre du Menu, le texte d'une invite d'Interaction, les sortes d'objets de l'Inventaire, les ressources, les outils et les verbes de la Collecte, le nom d'une Boutique, sa monnaie et ses articles, les titres, les descriptions, les étapes et les récompenses du Journal de quêtes ;
  • les propres textes des systèmes : « Jouer » et « Options » du Menu, « Acheter » de la Boutique, « Journal de quêtes », « Carte »... La colonne Où dit « texte du système ». Ils existent déjà en français et en anglais : leur case montre ce texte en gris, et le jeu l'affiche tant que vous n'en écrivez pas un autre. Dans les autres langues, ils attendent leur traduction comme les autres ;
  • le titre du jeu, et les noms des commandes que vous avez nommées ;
  • les textes des scripts écrits avec game.t("...").

Il y a une colonne par langue proposée. Une case rouge attend sa traduction : cliquez-la, écrivez, puis appuyez sur Entrée. En haut, chaque langue dit combien de textes il lui reste ; Seulement ce qui manque cache ceux qui sont déjà traduits. La colonne Où dit où chaque texte apparaît. Une traduction changée s'annule avec Ctrl+Z (et revient avec Ctrl+Y), comme toute modification dans l'éditeur.

Demander à l'agent¶

Le bouton Demander à l'agent de traduire envoie une demande à l'agent : il lit les textes qui manquent, les traduit en gardant le ton du jeu, et remplit les tables. Les cases se remplissent sous vos yeux ; vous pouvez ensuite corriger n'importe laquelle.

Les mises en forme restent

Un texte comme [b]Garde[/b] ou Il faut : {outil} garde ses balises et ses repères dans sa traduction : [b]Guard[/b], You need: {outil}. L'agent le sait ; si vous traduisez vous-même, recopiez-les.

Où sont rangées les traductions¶

Chaque langue proposée a sa table dans le projet, dans le dossier translations : translations/en.json pour l'anglais, translations/es.json pour l'espagnol. Une ligne par texte : le texte tel qu'il est écrit dans le jeu, puis sa traduction.

{
  "Bonjour, voyageur.": "Hello, traveller.",
  "Halte !": "Halt!"
}

Le fichier se lit et se corrige avec n'importe quel éditeur de texte, et se compare bien dans Git. Si vous changez un texte d'origine, sa traduction ne le suit pas : il réapparaît en rouge dans la fenêtre Traductions.

Le jeu exporté emporte ces tables avec lui.

Pour les scripts¶

Un script fait passer chaque texte qu'il affiche par game.t : game.hud_text("score", game.t("Pièces : {1}", pieces)). {1}, {2}... sont remplacés après la traduction, ce qui permet à l'ordre des mots de changer d'une langue à l'autre. Les textes des systèmes, eux, sont déjà traduits. La référence des scripts détaille game.language, game.languages et game.set_language.
