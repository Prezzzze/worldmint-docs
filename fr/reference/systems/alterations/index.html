Effets temporaires¶

Les bonus et les malus qui durent un temps : poison, régénération, rapidité, lenteur, force, faiblesse… Chacun se règle ici, sans code : sa durée, son cumul, ce qu'il change aux valeurs modifiables, ses dégâts ou soins réguliers. Une rangée d'icônes montre au joueur ceux qu'il porte.

Événements¶

Les descriptions viennent du code et sont en anglais, la langue de travail de l'agent.

Ce qu'il annonce¶

Événement Champs Description
alterations.debut cible (id), id (text), cumul (number), duree (number), encore (boolean), source (id?) A status effect was put on a carrier. encore is true when it was already there (its duration restarted, or it stacked: cumul is its new count).
alterations.fin cible (id), id (text), raison (text) A status effect left a carrier: its time ran out (fin), it was removed (retire) or the carrier died (mort). Its value bonuses are already gone.
alterations.tic cible (id), id (text), sorte (text), montant (number) A status effect hurt (degats) or healed (soins) its carrier at its regular interval; the health module was asked to do it.
sante.blesser cible (id), montant (number), source (id?) Ask the health module to remove health from an object.
sante.soigner cible (id), montant (number) Ask the health module to give health back, up to its maximum.

Ce qu'il écoute¶

Événement Champs Description
scene.change depuis (text), vers (text) Sent by the engine once the player has arrived in another scene of the game (game.go_to, or a passage). Scripts keep running across scenes: this is when a module looks at the objects of the new scene.
sante.mort cible (id), source (id?) An object's health reached zero. What happens next belongs to the game: the health module does nothing else, unless its setting says to destroy the object.
alterations.appliquer cible (id), id (text), duree (number?), source (id?), cumul (any?) Ask the Status effects module to put an effect on a carrier (a player, an enemy, an object), as game.status_apply does. duree in seconds (missing: the effect's own; 0: until removed); cumul: a number of stacks, or refaire, cumuler, ignorer.
alterations.retirer cible (id), id (text) Ask the Status effects module to remove an effect from a carrier, or every effect carrying that tag (an antidote removes poison).
langue.change langue (text) Sent by the engine when the player changes the game's language (game.set_language, the Menu options). A module redraws what it already shows: its texts go through game.t and game.language.

Points qu'un script peut remplacer (game.override)¶

Les descriptions viennent du code et sont en anglais, la langue de travail de l'agent.

  • alterations.avant : function(default, cible, id, options) -> options (the table, changed or not), or false to refuse. Called before an effect is put on a carrier (a player, an enemy, an object). options: {duree, source, cumul, genre, etiquettes = {tag = true}}. Refuse for an immunity (if options.etiquettes.poison and game.name(cible) == "Boss" then return false end), or change duree.
  • alterations.texte : function(default, key) -> the text shown for that key: restant ("{s} s"), minutes ("{m} min"), cumul ("x{n}").

Ce que l'agent sait de ce système¶

Le texte que l'agent lit avant de se servir de ce système (en anglais, la langue de travail de l'agent).

Status effects (alterations), shown as « Effets temporaires »¶

Buffs and debuffs that last a while: poison, regeneration, haste, slowness, strength, weakness. Not to be confused with game.effect (visual particles and death effects): this module is game rules. Use it whenever something should help or hinder for a time: a potion of speed, a poisonous wolf, a poison zone, a blessing at an altar.

  • Every effect is data, in the game setting effets (modules_configure): an « effet » row (id, nom, description, icone an image of the project or empty, forme the icon the engine draws without any file when there is no image: auto (the preset's own, otherwise a disc with the name's initials), goutte, coeur, fleche_haut, fleche_bas, sablier, epee, epee_bas, etoile, losange, triangle, carre, or empty for the disc, genre bonus or malus, etiquettes comma separated tags, duree in seconds or 0 until removed, cumul refaire / cumuler (up to cumul_max) / ignorer, tic aucun / degats / soins with tic_montant every tic_intervalle s through the Health module, particule and teinte on the carrier), followed by its « valeur » rows (the editor indents them under their effect and names it: « Valeur modifiée de : Poison »): valeur (any value: vitesse_deplacement, degats, sante_max, charge_max, endurance_max, or one a script declares), ajout (+n) and pourcent (+%). Six presets come with it (poison, regeneration, rapidite, lenteur, force, faiblesse): change them rather than writing code.
  • Value bonuses go through game.stat_bonus with the source alteration:<id> and are removed exactly at the end. A value nobody declared is declared by the module (vitesse_deplacement acts on the player's speed, predicted the same on a guest). Enemies read degats and vitesse_deplacement too.
  • Where effects come from, without code: a Healing potion's effets (ids, comma separated; such a potion can be drunk at full health); an enemy's effet and effet_chance (%) on each hit or shot that lands; the Trigger actions appliquer_alteration and retirer_alteration (alteration: an id, or a tag to remove; porteur: joueur, the player who triggered it, or cible; alteration_duree, 0 for the effect's own).
  • From a script: game.status_apply(target, id, {duree, source, cumul}), game.status_remove(target, id or tag), game.status_has, game.status_list. Events: alterations.debut, alterations.fin (raison fin, retire, mort), alterations.tic. Death removes the carrier's effects.
  • Hook alterations.avant (game.override): refuse (return false) or change an effect before it applies: an immunity (options.etiquettes.poison), a shorter duration. alterations.texte changes the HUD's texts.
  • What the player sees: a row of slots (settings afficher, ancrage, x, y, taille; by default centered at the top, under the clock, couleur_bonus, couleur_malus) with the icon (the creator's image first, otherwise the drawn shape: a drop for poison, a heart for regeneration, an arrow for haste, an hourglass for slowness, a sword for strength, a sword pointing down for weakness; an effect without image or shape gets a disc with two initials), the time left and the stack (x2) under it; hovering shows a tooltip with the name and description. Both are screens delivered by the system, which the user restyles in the screen editor: « Effets en cours » (the list Rangée, one Case per effect in the order they were applied: Effets en cours/Case#1...; installed from the model of its ancrage) and « Infobulle d'effet » (Bulle, Nom, Description). Never draw effect icons yourself, and do not name another screen like these. Theme roles: panneau.effets, case.effet.bonus, case.effet.malus, infobulle.effet.

Several players¶

The rule runs once, on the host, for every carrier. The row of icons is drawn by one copy per player and reaches that player. A player's effects and their time left are kept in their save and come back when it is loaded.
