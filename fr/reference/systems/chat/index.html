Chat¶

Le chat des parties à plusieurs : la touche T (réglable) ouvre une ligne, Entrée l'envoie à tous avec le nom du joueur, Échap annule. Les arrivées, les départs et les messages du serveur s'y écrivent. Les admins y tapent les commandes du serveur (/expulser Léa). Ce système règle tout cela : la touche, les noms des commandes et qui peut les utiliser, le signe des commandes, l'anti-spam, l'affichage et les textes. Sans lui, le chat marche avec ses réglages par défaut.

Points qu'un script peut remplacer (game.override)¶

Les descriptions viennent du code et sont en anglais, la langue de travail de l'agent.

  • chat.texte : function(default, key) -> the text the chat shows for that key: arrivee, depart, expulse, banni ({nom}), reserve_admins, inconnue ({commande}, {aide}), trop_vite, chat_coupe, sans_commandes, serveur, hote ({texte}), saisie (the input line's hint), aide_titre ({prefixe}); and every reply of the server commands: aide_<command> (what each command does in the help), aide_console, joueurs_compte ({nombre}, {max}), joueurs_ligne, sauve, arret_dans ({duree}), expulse_fait ({nom}), banni_fait ({qui}), usage ({commande}, {arguments}), relu, copies_titre, restaure ({copie}), reglage_fait ({reglage}, {valeur})... (the full list is the TEXTES table of chat.luau). The fields are replaced afterwards by the engine. The help a player asks for in the chat is put together on that player's PC, in their language. The default is the game's translation of the text in the original language (a built-in text of the chat in translations_get); without one, French or English, after the player's language. On a dedicated server, the game's original language.

Chat (chat)¶

The chat of games with several players (hosted by a player, or a dedicated server). The chat itself is in the engine and works in every multiplayer game, with or without this system: the control chat (T by default) opens a one-line input at the bottom left, Enter sends it, Escape cancels; the host checks the line (plain text, length bounded, anti-spam), then everyone sees it with the sender's name. Arrivals, departures and the server's messages (dire) are written in it. Add this system with modules_add when the user wants to change how the chat works: everything is a game setting, no code.

Game settings:

  • joueurs_parlent (players talk; off: only the game's messages and commands), messages_systeme (arrivals and departures), lignes (lines shown), duree (seconds before a line fades; the open chat shows them all), longueur_max (bytes per message, 200 at most), rafale and recharge (anti-spam: that many messages at once, then one more every recharge seconds).
  • prefixe: what starts a command (/ by default; 1 to 3 signs, no letter or digit).
  • commandes: one row per server command: commande (its fixed identifier: aide, joueurs, dire, expulser, bannir, debannir, bannir_ip, debannir_ip, blanche, admin, sauver, copies, restaurer, regler, arreter, motdepasse, motdepasse_web, recharger), noms (the names typed, comma separated: the first is its name, the others aliases, such as "expulser, kick, virer"; empty: off) and niveau (admin, tous, desactivee). The names work in the chat (after the prefix) and in the dedicated server's console; aide lists them as the game set them. An off command does not exist in the chat nor on the console. The web management page and the code use the identifiers, whatever the names.
  • Who is admin: on a dedicated server, a player whose verified key is in admins of serveur.json; in a game hosted by a player, the one hosting. A command at level tous can be typed by anyone.
  • The key: the control chat (Controls of the game settings, or the game's key menu). There is no gamepad button: typing needs a keyboard.

Scripts: game.chat_send(text, {joueur = id}?) writes a message of the game in the chat (to everyone or one player); the host hears chat.message (joueur, nom, texte) for each accepted line of a player (not the commands).

  • Texts follow the game's translations: the chat's own texts are built-in texts of the system, listed by translations_get (French and English are built in). Override chat.texte from a game script to change one: game.override("chat.texte", function(default, key) if key == "reserve_admins" then return "Réservé à l'équipe." end return default(key) end). Keys: arrivee, depart, expulse, banni ({nom}), reserve_admins, inconnue ({commande}, {aide}), trop_vite, chat_coupe, sans_commandes, serveur, hote ({texte}), saisie, aide_titre ({prefixe}). The answers of the commands themselves come from the server and are in French.
  • Testing: game_run with several players is not available yet; the engine tests cover the chat (test_dedicated_server).
