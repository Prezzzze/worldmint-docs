Référence¶

Ces pages sont générées depuis le code de l'éditeur : elles disent exactement ce qui existe.

  • Chaque élément de l'éditeur : ce que fait chaque champ, bouton et menu, zone par zone.
  • Les systèmes de jeu : chaque système, ses réglages, ses commandes et ses événements.
  • Les événements des systèmes : ce que les systèmes annoncent et écoutent.
  • Les scripts de jeu (Luau) : toutes les fonctions d'un script de jeu.
  • Ce que fait l'agent : ses outils, un par un.
  • Le guide de l'agent : la méthode qu'il suit.

Cette page est générée automatiquement depuis le code de WorldMint (tools/docs/generate.py) : elle suit toujours l'éditeur.
