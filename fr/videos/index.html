Les vidéos¶

Un jeu peut montrer des vidéos : une cinématique en plein écran (une introduction, une fin, un moment de l'histoire), ou une vidéo dans l'interface (un écran dans un menu, un portrait animé). Le son de la vidéo se joue avec elle, dans un groupe de la table de mixage : Voix pour une cinématique (la musique du jeu baisse pendant ce temps), Effets pour une vidéo dans l'interface ; le réglage « Son de la vidéo » ou l'option group en choisit un autre.

Les fichiers¶

WorldMint lit les vidéos MP4, le format le plus courant : celui des téléphones, des logiciels de montage et des sites de vidéos. Les fichiers M4V et MOV se lisent aussi quand ils contiennent la même chose (de l'image en H.264 et du son en AAC).

C'est Windows qui décode les vidéos : rien n'est à installer, ni pour vous, ni pour vos joueurs. Une vidéo qu'il ne sait pas lire (un autre format à l'intérieur du fichier) se signale par un message ; enregistrez-la alors en MP4 depuis votre logiciel de montage. Sur une édition « N » de Windows, sans lecteur multimédia, il faut ajouter le Media Feature Pack (Paramètres de Windows, Fonctionnalités facultatives) : sans lui, le jeu se joue, sans ses vidéos.

Dans la bibliothèque¶

Ajoutez à la bibliothèque un dossier qui contient vos vidéos (voir La bibliothèque). Chaque vidéo y a sa tuile, avec une image de son début ; l'infobulle donne sa durée et sa taille. Double-cliquez pour la regarder dans le lecteur de Windows ; le clic droit propose aussi Ouvrir l'emplacement du fichier et Copier le chemin. Le bas du panneau compte les vidéos de chaque dossier.

Une cinématique, sans code¶

Le Déclencheur a l'action Jouer une vidéo :

  1. Posez le Déclencheur sur un objet, et ajoutez une règle. Pour une introduction : Quand : Au début du jeu.
  2. Alors : Jouer une vidéo, puis choisissez la Vidéo dans la liste.
  3. Le joueur peut la passer : coché, Échap, Entrée, Espace, un clic ou A à la manette la passent ; une petite invite le rappelle en bas de l'écran. Décoché, elle se regarde jusqu'au bout.
  4. Événement envoyé à la fin (facultatif) : un nom, par exemple « intro_finie ». Il est envoyé quand la vidéo finit, ou quand le joueur la passe.

Pendant la vidéo, le monde est en pause : personne ne bouge, le temps du jeu ne compte pas.

Pour enchaîner, ajoutez une autre règle : Quand : Quand un événement arrive, avec le même nom (« intro_finie »), et Alors : ce qui vient ensuite, comme Aller à une autre scène ou Afficher un message. Une vidéo introuvable ou illisible n'arrête pas le jeu : l'événement est envoyé quand même.

Avec un script¶

L'agent peut aussi écrire un script :

  • game.video("videos/intro.mp4", {event = "intro_finie"}) joue une cinématique ; skip = false interdit de la passer, pause = false laisse le monde tourner derrière.
  • game.hud_video("ecran", "videos/boucle.mp4", {x = 0.05, y = 0.6, w = 0.3}) met une vidéo dans l'interface, à ses vraies proportions, en boucle ; game.hud_remove("ecran") la retire.
  • À la fin de chaque vidéo, le jeu annonce l'événement video.fin (voir Les événements).

Le détail est dans la référence des scripts.

L'essai de l'agent¶

Quand l'agent essaie le jeu sans fenêtre, il ne voit ni n'entend les vidéos, mais elles commencent et finissent aux mêmes instants qu'à l'écran : son rapport dit lesquelles ont joué, combien de temps, et si elles sont allées au bout, ont été passées ou arrêtées.

À l'export¶

Les vidéos citées par les règles et par les scripts partent avec le jeu exporté (voir Exporter un jeu). Le joueur n'a rien à installer.

Pas encore possible¶

Une vidéo sur un objet du monde, comme l'écran d'une télévision, n'est pas encore possible : elle viendra avant la bêta publique.
