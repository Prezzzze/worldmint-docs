Les commandes du jeu¶

Les commandes sont les touches du jeu : une commande par action du joueur. Elles se règlent dans l'onglet Jeu, section Commandes, et valent pour tout le jeu.

Chaque commande a :

  • un libellé, que voit le joueur (« Sauter ») ;
  • un nom pour les scripts (jump) : les scripts et les systèmes demandent « la commande jump est-elle appuyée ? », jamais une touche précise. Changer la touche ne casse donc rien ;
  • une touche (ou un bouton de souris, ou la molette) ;
  • un bouton de la manette, facultatif.

Au survol d'un libellé, l'éditeur montre le nom pour les scripts et d'où vient la commande : ce jeu, le moteur, ou le système qui l'a ajoutée.

Les commandes de départ¶

Un nouveau jeu a ces commandes. Les sept premières viennent du moteur ; Attaquer et Utiliser appartiennent au jeu, qui peut les retirer.

Commande Nom pour les scripts Touche Manette
Avancer move_forward W (Z sur un clavier AZERTY) stick gauche
Reculer move_back S stick gauche
Aller à gauche move_left A (Q sur un clavier AZERTY) stick gauche
Aller à droite move_right D stick gauche
Courir run Maj gauche LT
Sauter jump Espace A
Pause pause Échap Start
Attaquer attack Clic X
Utiliser interact E Y

Les touches sont lues par leur place sur le clavier, pas par leur lettre : l'éditeur affiche la lettre de votre clavier (Z sur un AZERTY, là où un QWERTY a W). Le stick droit de la manette tourne la caméra.

Certains systèmes ajoutent les leurs quand on les active : Parer (block, clic droit, LB) avec Combat simple, Boire une potion (heal, R, ↑) avec Soins. Voir la référence des systèmes.

Changer une touche¶

  1. Cliquez sur le bouton de la touche, à droite du libellé : il affiche « Une touche… ».
  2. Appuyez sur la touche, le bouton de souris ou le cran de molette voulus. Échap annule.

La liste à côté choisit le bouton de la manette (Aucun pour n'en mettre aucun) : A, B, X, Y, LB, RB, LT, RT, Start, Back, L3, R3 et les quatre flèches.

Changer une commande d'un système ou du moteur la garde dans ce jeu, avec la nouvelle touche. Ctrl+Z revient en arrière.

Ajouter une commande¶

Ajouter une commande ouvre un petit formulaire :

  • Nom pour les scripts : un mot sans espace (ouvrir_carte) ;
  • Libellé pour le joueur : « Ouvrir la carte » ;
  • Touche : cliquez, puis appuyez sur la touche.

Ajouter la crée (« Ce nom est déjà pris. » si une commande porte déjà ce nom). Un script la lit ensuite avec game.pressed("ouvrir_carte") : voir la référence des scripts.

La croix Retirer cette commande supprime une commande qui appartient au jeu. Les commandes du moteur et des systèmes ne se retirent pas : si vous avez changé leur touche, la retirer leur rend leur touche de départ.

Dans le jeu¶

  • La souris tourne la caméra. Quand le jeu montre un curseur (un inventaire, un menu), elle sert à cliquer.
  • Échap est la commande Pause : si aucun script ne s'en sert, elle libère la souris, pour cliquer hors de la fenêtre ou la fermer. Un clic dans la fenêtre la reprend.
  • Quand une partie se termine (gagnée ou perdue), l'écran affiche « R : rejouer Échap : quitter ».
  • Une manette branchée se prend aussitôt ; le jeu affiche alors les boutons de la manette dans ses invites.
  • Les fenêtres du jeu (menus, dialogues, inventaire, boutique, journal) se pilotent à la manette et au clavier : la croix, le stick gauche ou les flèches passent d'un bouton à l'autre, A ou Entrée clique, B ou Échap ferme. Tant qu'une fenêtre est pilotée ainsi, ces boutons ne déclenchent pas leur commande (A ne fait pas sauter). Voir La manette et le clavier.
  • Un script peut proposer au joueur de changer ses touches pendant la partie (game.bind).
