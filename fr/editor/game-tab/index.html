L'onglet Jeu¶

Le deuxième onglet de la colonne de gauche regroupe ce qui vaut pour tout le jeu, dans toutes ses scènes, et n'appartient à aucun objet : ses Commandes, sa Table de mixage et ses Systèmes.

Commandes¶

Une commande par touche du jeu : Avancer, Sauter, Attaquer... Les scripts lisent son nom, le joueur voit son libellé. Pour chacune, un bouton montre sa touche (cliquez, puis appuyez sur la touche voulue) et une liste son bouton de manette. Ajouter une commande en crée une nouvelle.

Tout est détaillé dans Les commandes du jeu.

Table de mixage¶

Chaque son du jeu appartient à un groupe : Musique, Effets, Ambiance, Voix, Interface, et ceux que vous ajoutez avec Ajouter un groupe. Pour chacun, un curseur règle son volume et le haut-parleur le coupe. Plus bas, l'Atténuation automatique fait baisser un groupe quand un autre joue (la musique sous les voix), et les Groupes assourdis étouffent un groupe en permanence.

Tout est détaillé dans Le son et la table de mixage.

Systèmes¶

Les systèmes sont des règles de jeu toutes faites : la santé, une barre de vie, le combat, des ennemis, un inventaire, la récolte, les sons, la physique, les passages entre scènes... La liste complète, avec chaque réglage, est dans la référence des systèmes.

Un système s'utilise en deux temps : on l'active pour le jeu, puis on le pose sur les objets qui doivent le porter.

Activer un système¶

Sous Ajouter un système, chaque système pas encore activé montre son nom et ce qu'il fait. Certains ont besoin d'un autre : « Active aussi : Santé ». Cliquez sur Activer.

Les systèmes activés¶

En haut de la section, chaque système activé a sa carte, repliée. Un clic sur son nom l'ouvre :

  • ce qu'il fait ;
  • où il est posé : « Posé sur 3 objets ou groupes », ou « Posé sur aucun objet pour l'instant » ;
  • ses réglages pour tout le jeu (ceux qui ne se règlent pas objet par objet), qui s'appliquent tout de suite ;
  • « Ses scripts ont été modifiés : ils restent tels quels » si un script du système a été changé à la main ;
  • Désactiver : le retire du jeu. S'il est posé sur des objets, l'éditeur demande confirmation (« Désactiver ce système ? ») et dit de combien d'objets il sera retiré, avec leurs valeurs ; Garder renonce. Ctrl+Z rend tout. Un système dont un autre a besoin ne se désactive pas : le bouton le dit au survol (« Le système « Combat simple » en a besoin »).

Poser un système sur des objets¶

Une fois activé, un système qui se pose sur des objets apparaît dans le dossier Systèmes de la bibliothèque. Pour le poser :

  • glissez-le depuis la bibliothèque sur un objet ou un dossier, dans la liste de la scène ou dans la vue 3D ; sur le sol d'un terrain, il va sur le Terrain ;
  • ou double-cliquez sur lui dans la bibliothèque : il va sur la sélection ;
  • ou, dans les Propriétés d'un objet, section Systèmes, cliquez sur + Système.

Posé sur un dossier, un système vaut pour tout ce que le dossier contient : une seule fois pour toute une troupe d'ennemis. Ses réglages par objet se changent ensuite dans les propriétés : voir Les systèmes d'un objet.
