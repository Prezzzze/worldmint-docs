Le son et la table de mixage¶

Un jeu WorldMint joue des fichiers WAV, MP3, OGG ou FLAC de votre bibliothèque : des bruits de pas, des coups, une ambiance de feu, une musique. Le système Sons les pose sur ce qui les fait, sans code (voir sa référence) ; un script les joue avec game.sound et game.music (voir la référence des scripts).

Tous ces sons passent par la table de mixage du jeu : elle règle l'équilibre entre la musique, les bruits, l'ambiance et les voix, pour tout le jeu et toutes ses scènes.

Les groupes de sons¶

Chaque son appartient à un groupe. Un nouveau jeu en a cinq, qui restent toujours là :

Groupe Nom pour les scripts Ce qu'on y range
Musique music la musique de fond, la musique de combat
Effets effects les bruits : pas, coups, portes, récolte (par défaut, tout son sans groupe)
Ambiance ambience les boucles d'un lieu : un feu, une rivière, le vent
Voix voice ce que disent les personnages
Interface ui les petits signaux : un clic de menu, un objet ramassé

Ils se règlent dans l'onglet Jeu, section Table de mixage :

  • le curseur règle le volume du groupe, de 0 à 100 % ;
  • le haut-parleur le coupe (on ne l'entend plus) ; un second clic le rétablit ;
  • Ajouter un groupe en crée un nouveau : une radio, la voix d'un boss. Son nom suffit ; le nom pour les scripts s'en déduit (« Radio de bord » donne radio_de_bord), et apparaît au survol. La croix retire un groupe ajouté ; les cinq de départ ne se retirent pas.

Baisser un groupe change d'un coup tous ses sons : pour une ambiance trop forte, baissez Ambiance plutôt que chaque feu.

L'atténuation automatique¶

Une règle d'atténuation fait baisser un groupe tant qu'un autre joue, puis le fait remonter : la musique passe sous les voix, sans script. Un nouveau jeu en a une : Voix fait baisser Musique à 40 %.

Dans la section Atténuation automatique :

  • Quand ce groupe joue : le groupe qui déclenche (un son trop loin pour être entendu ne compte pas, ni un groupe coupé) ;
  • Baisser ce groupe : celui qui baisse ;
  • Jusqu'à : ce qu'il garde de son volume ;
  • Descente et Remontée : en combien de secondes il baisse, puis revient une fois le silence revenu.

Ajouter une atténuation en crée une autre ; Retirer cette atténuation la supprime.

Assourdir le son¶

Un groupe assourdi perd ses aigus, comme entendu sous l'eau, derrière un mur ou à travers une radio. De 0 (son clair) à 1 (sous l'eau).

  • En jeu, le plus souvent : une règle du Déclencheur avec l'action Assourdir le son. Par exemple sur une zone posée sur l'eau : « en entrant », assourdir Tout le son du jeu à 1 ; « en sortant », à 0. L'action Couper ou rétablir un groupe de sons fait taire un groupe (l'ambiance pendant une scène racontée), puis le rend.
  • En permanence : la section repliée Groupes assourdis étouffe un groupe pour tout le jeu.

Il n'y a pas encore d'écho ni de réverbération.

La fenêtre du jeu en arrière-plan¶

Quand le joueur réduit la fenêtre du jeu, ou passe à une autre fenêtre (un navigateur, une discussion), la section repliée Fenêtre du jeu en arrière-plan décide du son :

  • Couper le son (le réglage de départ) : le jeu se tait, puis reprend quand le joueur revient ;
  • Baisser le son : il continue, plus bas (Baissé à, 30 % par défaut) ;
  • Garder le son : rien ne change, pour un jeu qu'on écoute en faisant autre chose.

Le son s'éteint et revient en douceur, sans claquer. Un jeu lancé en arrière-plan pour un essai (par l'agent ou les tests) reste toujours muet : on n'entend jamais un essai qu'on ne regarde pas.

Le menu Options du joueur¶

Le système Menu propose au joueur, dans Options, section Son, le Volume général et un réglage par groupe de la table de mixage, sous son nom dans la langue du joueur. Son choix s'ajoute à votre mélange : s'il met la musique à 50 % et que vous l'avez réglée à 80 %, elle joue à 40 %.

Dans les scripts¶

  • game.sound(fichier, {group = "ambience"}) range un son dans un groupe, par son nom pour les scripts ou par son nom (« Ambiance ») ; sans group, il va dans Effets. game.music va dans Musique.
  • game.mute(groupe, true) coupe un groupe, game.mute(groupe, false) le rétablit ; "master" vaut pour tout le son.
  • game.muffle(groupe, 0.8, {fade = 0.5}) l'assourdit, en une demi-seconde.
  • game.volume(groupe, 0.5) règle le volume du joueur, pour un menu d'options à vous.
  • game.sound_groups() donne la liste des groupes, avec leur nom dans la langue du joueur.

Un groupe qui n'existe pas est une erreur, que la console du jeu affiche.

Avec l'agent¶

L'agent range les sons qu'il écrit dans le bon groupe, règle l'équilibre avec la table de mixage plutôt qu'en changeant chaque son, et pose les règles du Déclencheur pour l'eau ou une grotte. Quand il essaie le jeu, son rapport dit combien de sons ont joué dans chaque groupe, et ce que les scripts ont coupé ou assourdi.
