Exporting a game¶

Exporting turns your game into a standalone folder, with its .exe program, that anyone can run on Windows, without WorldMint. Like WorldMint, the game needs a graphics card that supports Vulkan 1.3, with an up-to-date driver: otherwise, it tells the player as soon as it opens.

Exporting¶

  1. Check that the game has a player (Set as player on a character): without a player, Export game... is greyed out.
  2. Give the game a title: in the game's settings (nothing selected), Game window section, Title field ("Jeu" at first). The folder and the program take this name; without a title, the project's.
  3. File > Export game..., then choose the folder to put it in.

The status bar shows "Exporting the game...", then "Game exported: ... (15 MB)", and the folder opens in File Explorer. The editor stays usable during the export.

The agent can also export the game for you.

What the folder contains¶

My game/
  My game.exe       the game
  locales/          its texts, in French and English
  data/             its scenes, and only the models, animations, sounds and images it really uses

All the project's scenes go with the game, as they are saved (the open scene, as it is on screen). The exported game starts on the project's start scene, whichever one you were looking at.

The checks¶

  • Before replacing anything, the editor runs the exported game, without a window, to check that it starts. If it does not start, the export is refused ("The exported game does not start: ...") and the previous export stays intact.
  • An export replaces the previous one in the same folder. A folder with the same name that is not an export is never overwritten ("This folder exists and is not an export"). If the exported game is still open, close it first.
  • Warnings (a file named by a script but missing, a path specific to your computer...) show in the console, starting with "Export warning".

Players' saved games (game.save in a script) are kept between two plays of the exported game.
