Interaction¶

The player uses with a key what carries this system: a door, a merchant, a lever. Shows the prompt, and leaves the effect to the game.
Identifier interaction
Version 6
Placed on objects yes

Settings for the whole game¶

In the Game tab, Systems section, by opening the system's card.

Setting What it does Name in code Type Default Limits or choices
Reach (m) How far, in meters, the player can use an object from; the prompt appears in front of the nearest one in reach. 2.5 m: they have to come close. distance Number 2.5 from 0.2 to 50
Player action The game's control action that uses the object ("interact": E by default). action Text interact
Show the prompt on screen Shows on screen the key and the name of the object in reach, such as "E: Door". invite Yes or no yes

Settings on each object¶

In the Properties of an object or folder that carries the system, Systems section. A folder passes its values on to what it contains; an object can change a value for itself only.

Setting What it does Name in code Type Default Limits or choices
Prompt text (empty: the object's name) The prompt text in front of this object, such as "Open" or "Talk". Empty: the object's name. texte Text (empty)

Events¶

The descriptions come from the code.

What it announces¶

Event Fields Description
interaction.proche cible (id?) The object the player can use changed: a new one is in reach, or none (cible missing).
interaction.utiliser cible (id), joueur (id) The player used the object in reach: a door, a merchant, an item to pick up. Whoever owns that object decides what it does.

Points a script can replace (game.override)¶

The descriptions come from the code.

  • interaction.texte: function(default, id) -> the prompt text for this object, after the key. The default is its texte setting, or its name. For a door that says Open or Close.

The text the agent reads before using this system.

Interaction (interaction)¶

Lets the player use the nearest object carrying this system with a key (interact, E by default), and shows a prompt such as "E : Door". It never decides what using does.

  • Make an object usable: place the system on it with systems_attach, or on a group so that all its children are usable. Its prompt shows texte if set (systems_set, such as "Open" or "Talk"), otherwise the object's name: name it in the user's language.
  • React when it is used: game.on("interaction.utiliser", function(e) if e.cible == door then ... end end). Doors, merchants, levers and talks are scripts of the game that listen to this event.
  • interaction.proche tells which object is in reach, or none (cible missing): use it to highlight something.
  • Items to pick up carry the system inventaire, which places this one with it: do not handle them yourself.
  • For the whole game: the reach, the action, and whether the prompt shows. The prompt uses the HUD key interaction.invite.

Several players¶

One copy per player: each player has their own prompt, and interaction.utiliser carries joueur, the player who used the object.
