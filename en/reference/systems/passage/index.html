Passage¶

What carries this system leads to another scene of the game: a door into a house, a cave entrance, a level's exit. One arrives at the chosen object of that scene, after a fade to black.

Version 3
Placed on objects yes
Also activates Interaction
Also needs, on the same object Interaction

Events¶

The descriptions come from the code.

What it listens to¶

Event Fields Description
interaction.utiliser cible (id), joueur (id) The player used the object in reach: a door, a merchant, an item to pick up. Whoever owns that object decides what it does.
scene.change depuis (text), vers (text) Sent by the engine once the player has arrived in another scene of the game (game.go_to, or a passage). Scripts keep running across scenes: this is when a module looks at the objects of the new scene.
joueur.depart joueur (id), numero (number) Sent by the engine on the host when a guest leaves the game (they quit, or their connection was lost): their character is removed right after. A module forgets what it kept for them.

Passage (passage)¶

Leads to another scene of the game: a door into a house, a cave entrance, the exit of a level. Activating it activates the interaction module; placing it on an object places interaction there too.

  • A game with several places has one scene per place, in the project's scenes folder. A scene's name is its file name, without folder or extension.
  • Place it on the door, the entrance or a zone (systems_attach), and set (systems_set): scene (where it leads, a name from scenes_list), arrivee (the name of an arrival point of that scene, where the player appears turned like it: entities_create with arrival: true, just inside the door), en_marchant (true: taken by walking into it within distance, without a key; false: with the interaction key).
  • Make the way back too: a passage in the other scene, leading to an arrival point just outside the first door. An arrival on a passage taken by walking does not send the player back at once (they must step out first), but keep them apart: the player would be standing in a doorway.
  • scene_validate lists passages that lead to a missing scene or arrival.
  • The player keeps everything (inventory, health, quests): scripts keep running. A scene left stays as it was.
  • From a script: game.go_to(scene, arrival?), and game.on("scene.change", function(e) ... end) with e.depuis and e.vers.

Several players¶

One for the whole game: the whole group changes scene together. By default the passage waits until every player has taken it (groupe = attendre, showing "Waiting for the group: 2 of 3"); emmener takes everyone as soon as one takes it.
