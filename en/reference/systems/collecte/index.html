Gathering¶

What carries this system is a resource to gather: a tree to chop, a rock to mine, a bush to pick. Each use is a hit; at the last one, the resource gives what it holds to the inventory, disappears, and grows back if wanted.
Identifier collecte
Version 8
Placed on objects yes
Also activates Interaction
Also needs, on the same object Interaction

The descriptions come from the code.

What it announces¶

Event Fields Description
collecte.coup cible (id), coups (number), restants (number) The player hit a resource (a use of something carrying collecte). restants is how many hits are left before it is used up.
collecte.recolte cible (id), ressource (text), quantite (number), joueur (id?) A resource was used up and gave what it holds. The inventory, if present, has been asked to add it.
collecte.epuise cible (id) A resource is used up and is about to disappear (destroyed, or hidden until it grows back): it still exists while this is sent.
collecte.repousse cible (id) A used-up resource grew back and can be gathered again.
collecte.outil_manquant cible (id), outil (text), joueur (id?) The player tried to gather a resource without the tool it needs: not held in hand (the default, with attack), or not in the inventory (gathering set to the interaction).
inventaire.ajouter objet (text), quantite (number), joueur (id?) Ask the inventory to add items, such as a reward. Answered by inventaire.change, or inventaire.plein. With several players, joueur says whose bag; without it, the player whose action is being handled, or every player.
action.prise action (text), prise (boolean), par (text), joueur (id?) A system takes a control action for itself, or gives it back (prise false) (version 24): gathering takes attack while the player aims at a resource that needs a tool, so the press chops instead of swinging a weapon. par names who says it ("collecte"). Fighting modules do not strike with that action while any system holds it.

What it listens to¶

Event Fields Description
interaction.utiliser cible (id), joueur (id) The player used the object in reach: a door, a merchant, an item to pick up. Whoever owns that object decides what it does.
inventaire.change objet (text), quantite (number), total (number), chargement (boolean?) The quantity of an item changed. total is the new quantity. chargement is true when a saved game gives the items back (game.load): nothing was picked up.
inventaire.en_main objet (text), avant (text), place (number), chargement (boolean?), joueur (id?) What the player holds in hand changed (version 24): the slot chosen in the inventory's bar (keys 1 to 9, wheel), an item used up, a load (chargement true). objet is the kind held, "" for empty hands; avant the one held before; place the bar slot (0: nothing). Gathering checks the tool held; a game script equips a sword with it.
joueur.occupe occupe (boolean), par (text) The player's hands are taken by something else than fighting (version 23): a building mode where the click places a piece, a tool being aimed. occupe true when it starts, false when it ends; par names who says it ("construction"), so several can overlap. Fighting modules do not strike nor block while any of them keeps the player busy.
joueur.depart joueur (id), numero (number) Sent by the engine on the host when a guest leaves the game (they quit, or their connection was lost): their character is removed right after. A module forgets what it kept for them.

Gathering (collecte)¶

Makes what the user calls a resource gatherable: a tree to chop, a rock to mine, a bush to pick, any model. Activating it activates the interaction module; placing it on an object places interaction there too.

  • A resource: an object carrying this system (systems_attach), every child of a group carrying it, or every plant of a plant kind object carrying it (a whole forest at once, see the terrain rules). Set per object or group (systems_set): ressource (what it gives, in the user's language; empty: its name without a trailing number), quantite, coups (uses before it is used up), repousse (seconds before it grows back; 0: never), outil (an item the player must hold in hand, such as "Axe"; empty: bare hands), verbe (the prompt word: Chop, Mine, Pick).
  • A resource with an outil is struck with the attack (left click, X on a gamepad), the tool held in hand: the inventory's bar (keys 1 to 9, the wheel) chooses what is held, announced by inventaire.en_main. This is the user's decision for every game (ADR-029, 11 November 2026). The player aims like the game is seen: the centre of the screen with a character, else what is in front of them, within the interaction reach measured at the trunk or the foot. With the tool only in the bag the message says to take it in hand (message_en_main); without it, message_outil; no hit either way. While the player aims at such a resource, gathering takes the attack (action.prise): combat.basique does not swing too. Holding the attack chains the hits. The game setting recolte_outil = interaction brings back the old way (E, the tool in the bag); do not change it unless the user asks.
  • A resource without outil (berries, a bush) is gathered with the interaction (E by default): each use is one hit. At the last one, what it gives goes to the inventory (inventaire.ajouter: activate inventaire too, or listen to collecte.recolte yourself), and the resource disappears: destroyed, or hidden until it grows back.
  • The prompt shows the key, the verb, the tool to hold in brackets, and the hits so far ("Click: Chop 2/3").
  • animation: a clip of the player's model, read with animation_clips (names differ from one model to another: never guess). The player then turns to the resource and plays it in place; the hit counts at moment (% of the clip, 50 by default), and the gesture lasts the clip's length divided by vitesse_animation. Holding the key chains the hits. Without it, or if the player lacks the clip, each use is an instant hit.
  • Its end, when used up (fin): disparait (vanishes at once, the default), tombe (falls away from the player), seffondre, retrecit, eclate, over duree_fin seconds; it stops blocking at once. If the resource's own model has an end animation, set animation_ressource to it (read its clips with animation_clips on its own file): it replaces the end. secousse (on by default) shakes it at each hit. Its sounds belong to the resource, not to the end: the sons module's recolte_coup and recolte_fin on the resource or its plant kind.
  • React with game.on: collecte.coup (cible, coups, restants) for a hit sound or wood chips, collecte.recolte (cible, ressource, quantite), collecte.epuise (cible, sent before it disappears: read its position to drop logs there), collecte.repousse (cible), collecte.outil_manquant (cible, outil).
  • Give the tool with game.emit("inventaire.ajouter", {objet = "Axe", quantite = 1}), or make an axe an item to pick up with inventaire: it goes into the bar, and into the hand if its slot is the chosen one (game.emit("inventaire.tenir", {objet = "Axe"}) puts it in hand). Its model shows in the hand by itself (see inventaire). Never write your own hotbar, held item or attack-to-gather script: these systems do it.
  • Do not put inventaire on a resource: it would be picked up whole at the first use.
  • Change what a resource gives from your script with game.override("collecte.don", function(default, id) ... end): it returns the resource name and the quantity.
  • Saved games: game.save keeps the hits already struck and the time left before each regrowth (the engine keeps the resource hidden or destroyed); game.load gives them back. Nothing to write.
  • In a large world, resources stay loaded (they carry a system) and asleep when far; one gathered far away still grows back on time.
  • A survival game: collecte gives the materials, fabrication turns them into tools and food, construction spends them on a shelter, besoins makes food matter, jour_nuit gives days and nights. The resource names must match the recipes' and pieces' items exactly.

Several players¶

One for the whole game: resources are shared (a tree cut down is cut for everyone, its regrowth too), but each player has their own gesture, tools, message, and what they harvest goes into their own bag (inventaire.ajouter with joueur).
