The properties¶

The Properties panel, at the top of the right column, shows the settings of what is selected. With nothing selected: the game's settings. The content changes with the kind of object: a played character shows its movement, a camera what it looks at, a terrain region its vegetation.

At the top, a card says what the object is: its icon, its name, and its kind (the model's file name, Basic shape, Folder, Played character, Camera, Arrival point, Terrain, Terrain region, Terrain water or Plant kind), with a sentence of explanation.

Changing a value¶

Number fields are set in two ways: "Click to type a value, or drag to adjust it (Alt: finer)." A drag, however long, is undone with a single Ctrl+Z. Three-value fields give X (red), Y (green, up) and Z (blue), in metres.

An object¶

The buttons at the top¶

  • Place on ground (End key): sets the object on what is below it.
  • Set as player: makes this model the character you play. See The player.

Position and size¶

Field Effect
Position Where the object is in the world, in metres.
Rotation Its rotation, in degrees, around X, Y and Z. A horizontal half-turn shows as "0, 180, 0". (Absent for a camera that follows an object: it turns by itself.)
Scale Its size, per axis: 1 is the original size.

Appearance¶

Field Effect
Collision The player and characters cannot pass through it. For an object carrying the Physics system, the row says instead "Movable: it collides with everything (Physics system)".
Color Tints the model or colors the shape. White changes nothing.
Visible in game Unchecked, the object is not seen in the game (a model that scripts copy, for example). It stays visible in the editor.

Held by the character¶

For an object placed inside an animated character (a sword in the hand, a bag on the back):

  • Attached to bone: choose a bone of the skeleton in the list (a search filters their names). In the game, the object follows this bone as the character animates. Choosing a bone places the object on it; then adjust it if needed, on the rest pose. None: it follows the character detaches it from the bone.
  • Place on the bone: places and orients it like the bone again.

An object's systems¶

The Systems section lists the systems the object carries, with their per-object settings. Each system's settings are described in the systems reference.

  • + System places an activated system the object does not carry yet. (To activate a system, see The Game tab.)
  • The cross to the right of a system's name removes it from this object. A system that another system of the object needs cannot be removed alone: it is marked "Needed by ...".
  • Inheritance: a system placed on a folder applies to everything inside. An object in the folder shows "Inherited from the folder “Enemies”". If it changes a value, the value is marked Changed on this object, and the arrow beside it goes back to the folder's value; the other values stay the folder's ("Value of the folder “Enemies”").
  • Do not inherit: cuts inheritance for this object and what it contains. Restore inheritance brings it back.
  • "Nothing to set on the object: its settings apply to the whole game": this system is set in the Game tab.

A copy of a reusable object¶

The Reusable object section says which object this is a copy of ("Copy of “House”"). If the copy was changed:

  • Apply to all copies: every copy takes these changes;
  • Discard my changes: the copy becomes like the reusable object again.

Detach from the reusable object makes it an ordinary object, which no longer follows the other copies.

Details¶

Folded at first:

  • Dimensions: the object's real size, in metres;
  • Triangles: the number of triangles of its model;
  • Tags: words by which scripts find the object ("merchant", "coin"), separated by commas.

Several objects¶

With several objects selected, the panel says "3 objects selected". "The gizmo and these fields act on the whole selection, around its center":

  • Center: moves the whole set;
  • Turn by: turns the set by these degrees, then the field goes back to zero;
  • Multiply size by: enlarges or shrinks the set, then goes back to 1;
  • Collision (or Collision (some) if only some have it): for all;
  • Place on ground, Duplicate, Delete;
  • Systems, + System: each selected object receives the system. To set it once for all, put them in a folder (Ctrl+G) and place it on the folder.

The player¶

When the played character is selected, its settings come first. "Press F5 to play and tune live": while the game runs, each change applies to it at once.

Movement¶

Field Effect
Walk speed In m/s.
Run speed In m/s, while holding the run key.
Jump strength The jump's starting speed, in m/s.
Swim speed In m/s, in deep water.
Acceleration In m/s²: how fast it reaches its speed.
Turn speed In degrees per second: how fast it turns towards where it goes.
Gravity In m/s².
Fall limit In metres: if it falls below this height, it respawns.
Face the camera It always faces where the camera looks, instead of turning towards where it goes: it walks sideways or backwards, as in a shooter.
While holding the control (without the setting above) A game control, aiming for example: while it is held, it faces the camera. None: it always turns towards where it goes.

Reset to defaults puts these settings back to their starting values.

Animations¶

  • Animation files: the files the character's moves come from. Add an animation file picks one from the library; the Remove this file cross removes it. The number of moves available shows above.
  • One row per situation: Idle, Walk, Run, Jump, In the air, Landing, Swim, Fall... For each, choose the move it plays. The eye Show this move in the scene shows it on the character, in the view.
  • Advanced animation settings (folded), in two tabs:
    • Situations: each situation, with its name, its move, its Playback speed (× 1 = normal), Looping, and At start (the starting situation). Add a situation creates one; the cross deletes it. A looping situation (a walk, a run) has its moves By direction: Move backwards, to the left, to the right, and the diagonals Move forward-left, forward-right, back-left, back-right. When the character faces the camera, they are blended with the situation's move (forward) according to the direction taken, on 8 directions: between two neighbouring directions, shared by the angle. A diagonal with no move (Blend of its neighbours) is shared by its two neighbours: half one, half the other, as on 4 directions. Without any of them, the situation's move is used in every direction, as before; when a side one is missing, it stands in for it (played in reverse to walk backwards). Script characters have their own (game.character, walk_directions and run_directions, with strafe).
    • Sequences: when to go from one situation to another. Each sequence goes from a situation (or from Any situation) to another, with conditions (Speed, Share of run speed, Vertical speed, On the ground, Time in the air, Jump started, Movement input, Run key, Time in the situation, Move progress), a comparison sign, a value, and a Fade in seconds. Condition adds a condition. "The first possible sequence in the list wins": the Higher priority and Lower priority arrows change the order. Add a sequence creates one. Three values serve walking sideways: Forward speed (negative backwards), Sideways speed (positive to its right) and Facing the camera (1 when it faces the camera).
  • Feet on the ground: on a slope, a step or a terrain, each foot rests on the real ground (moving objects included: a platform, a boat, a vehicle), and the hips lower as needed, for the foot touching the ground only: the leg the animation lifts (the one swinging forward while walking) follows the body without going under the ground. Largest feet gap: the largest gap corrected under a foot, in metres. The engine looks for the legs in the skeleton (a foot, a knee, a hip); without them, it says so, and nothing changes.
  • Animation borrowing (on by default): a file made for a character with the same bones but other proportions (taller, stockier) is played with this character's proportions: its rotations only, and the hips' movement scaled to its legs. Limbs do not float. The file then shows (adapted). A file made for a skeleton whose bones have other names (Mixamo, Unreal, Blender, Unity…) is borrowed: bones are found on their own, by their name and then by the shape of the skeleton (spine, arms, legs, left and right), and the move is replayed on the character, even when its rest pose differs (arms in a T or an A). The file then shows (borrowed). Off, moves are read as they are, by bone names.
    • Bone matching (opens by itself when a bone is to check): for each body bone of the character, the bone of the file it follows, and where that choice comes from: by name, by shape, same name, by hand, or to check when the clue is weak. Choose another bone of the file in the list if it is wrong, (none) so that it keeps its rest pose, or Automatic choice to go back to the engine's choice. Show all bones adds fingers and helper bones. File shown picks the file when several are borrowed.
    • The preview shows both skeletons side by side, the file on the left and the character on the right, playing the Preview move: they should strike the same pose. Hover a bone in the list: it lights up on both sides.

Player camera¶

The camera that follows the character in the game.

Field Effect
Distance Its distance to the character, in metres.
Target height The height of the point it looks at, above the feet.
Field of view In degrees: wider shows more.
Tilt Its downward angle, at the start.
Mouse sensitivity In degrees per mouse pixel.

More camera settings (folded): Min tilt and Max tilt (how far it can go down or up), Return after obstacle (how fast it comes back after moving closer because of a wall), Obstacle margin, Minimum distance.

Character body¶

Folded at first. "The invisible shape that stops it at walls and lets it climb steps": Radius, Height, Step height (the highest step it climbs without jumping), Maximum slope (in degrees), Mass (in kilograms, 70 by default: the heavier it is, the less a thrown crate or a rock knocks it).

A camera¶

A placed camera (Create > Camera) shows the game from where it stands; it is not seen in the game. When selected, it shows in a corner of the view What this camera shows.

Field Effect
Field of view In degrees.
Look at Straight ahead (it looks along its rotation), or an object of the scene it keeps in view.
Opens the game The game starts on this camera, instead of the one following the player.
  • Move to current view: the camera takes the position and direction of the 3D view.
  • Look through this camera: the 3D view takes its place.

Scripts switch cameras during the game: see the scripts reference.

A light¶

A placed light (Create > Light) lights around it; it is not seen in the game, only its light. In the view, an icon marks its place, and its range when selected. Its color is the object's Color. See Light and shadows.

Field Effect
Kind of light Bulb (all around) or Spotlight (a cone toward the bottom of the object: turn it to aim).
On Off, it stays in place; the Trigger or a script switches it back on.
Light intensity Its strength at 1 m; it falls off with distance.
Light range How far it lights, in meters.
Spotlight opening The width of its cone, in degrees.
Light's shadows What it lights casts its shadow (only a few lights at a time).
Shadow softness With its shadows: the size of what gives the light, in meters (0 sharp, 0.3 a lantern).

An arrival point¶

"The player appears here, facing the arrow, when a passage or a script brings them into this scene." The Arrival point section lists the passages leading here, in every scene of the game. See Projects and scenes.

The terrain, its regions, its plants¶

The Terrain, its regions, its water and its plant kinds have their own settings: see The terrain.

Nothing selected: the game's settings¶

With nothing selected (or after a click on the game row, at the top of the Scene tab), the card carries the game's title and says "Nothing selected: the game's settings".

Terrain¶

Without a terrain, the Terrain section offers to generate one; with a terrain, Edit the terrain selects it. See The terrain.

Sky and light¶

Field Effect
Sky The color of the sky.
Background The color behind everything else.
Sun color The color of its light.
Sun intensity Its strength.
Sun direction Where its light comes from (X, Y, Z).
Light from the ground The color of the light bounced by the ground, which lights the underside of objects.
Exposure How much light reaches the image, as on a camera: 1 leaves it as it is.
Automatic exposure The image brightens in a dark place and comes back outside, like an eye getting used to it; with Brighten up to, Darken up to and Adaptation time.
Sun shadows Objects, terrain and plants cast their shadow.
Shadow quality For the sun and the lights: Depends on the computer (low on an integrated chip, high on a graphics card), High, Medium, Low or Off (no shadows).
Shadow distance How far around the camera they are drawn, in meters.
Shadow softness The size of the sun, in degrees: 0 sharp, 0.5 the real sun, up to 10 very soft. Sharp at the foot of an object, softer further from it.
Fog distance At this distance, the fog hides almost everything; 0: none (only the horizon fade remains).
Fog color, Fog altitude, Thins out with height Its color; the altitude where it has its thickness, and every how many meters it halves above it (0: the same everywhere).
Glow of bright lights The glow around what shines very brightly; 0: none.

In detail: Light and shadows.

Game window¶

Field Effect
Title The title of the game window, and the name of the exported game.
Width, Height The window size, in pixels.
Fullscreen The game fills the whole screen.
Synced with the screen Frames follow the screen's rhythm (no image tearing).
Upscaling Draws the scene smaller, then enlarges it by blending the frames that follow one another: faster, and edges no longer look jagged. Off by default. See display settings.
Anti-aliasing Without upscaling: TAA (sharp in motion), SMAA (sharp, no trails), FXAA (lightest) or None; Automatic (the default) follows the quality: TAA in High and Medium (SMAA in a project from before November 2026), FXAA in Low. See anti-aliasing.
Allow ray tracing The player may draw shadows and reflections by ray tracing, on a card that has it (their choice: Automatic, On or Off, in the game's menu). Unticked: the game is always drawn without it. Ticked by default. See ray tracing.

Character walking¶

Folded at first. The typical character for whom the walkable areas are computed (see character walking).

Field Effect
Character radius Half its width, in metres: it keeps this distance from walls.
Character height It walks under anything higher.
Steepest slope In degrees: beyond it, the ground isn't a walkable area.
Highest step In metres: what it steps over without a detour.

Technical settings¶

Folded at first; you almost never touch them.

Field Effect
View distance Beyond it, nothing is drawn.
Nearest visible distance Closer than it, nothing is drawn.
Rate The number of simulation steps per second.
Max catch-up How many simulation steps the game catches up at most, per frame, after a slowdown.
Max physics bodies The number of objects physics can follow. "The number of bodies applies the next time the game starts."
Warning: tiny model, Warning: huge model In metres: a smaller or larger model is reported as having an unusual size.
