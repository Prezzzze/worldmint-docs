Menus and shortcuts¶

The top bar¶

On the left, the menus. In the middle, five buttons:

Button Effect
Globe: World axes / Object axes The gizmo follows the scene's axes, or those of the turned object.
Magnet: Snapping: moves by grid steps Moves, rotations and sizes go by steps (set in the Preferences).
Four squares: Four views (Q) Splits the 3D view in four.
Arrows: Undo (Ctrl+Z), Redo (Ctrl+Y) Undoes or redoes the last change.

On the right: the gear opens the Preferences, and Play (F5) starts the game; during the game, the button becomes Stop.

File¶

Command Shortcut Effect
New project... Creates a project in a new folder, then offers the creation assistant.
Open project... Opens a .worldmint file.
Open project folder Opens the project folder in File Explorer.
Create a project from this scene... For a scene outside a project: makes it a project, copying its models into it.
New scene... Ctrl+N Asks where to save it, then opens an empty scene. In a project, the + of Game scenes is simpler: see Projects and scenes.
Open... Ctrl+O Opens a scene (.wmscene).
Open recent scene The last scenes opened; on hover, their path.
Save Ctrl+S Saves the scene.
Save as... Ctrl+Shift+S Saves it to another file.
Export game... Turns the game into a folder with its program: see Exporting a game. Only possible when the game has a player.
Preferences Opens the Preferences in the right column.
Quit Closes the editor (offering to save).

Select¶

Command Shortcut
Select all Ctrl+A
Invert selection Ctrl+I
Select nothing

Object¶

Command Shortcut Effect
Create Folder, Camera, Arrival point, Zone, Cube, Sphere, Cylinder, Capsule, Plane: see The Scene tab.
Make a reusable object With a single object selected: see The library.
Group Ctrl+G Puts the selection in a new folder.
Ungroup Ctrl+Shift+G Takes the folder's contents out.
Place on ground End Sets the selection on what is below it.
Reset rotation to zero
Reset scale to 1
Turn collision on The player and characters no longer pass through.
Turn collision off

View¶

Command Shortcut Effect
Perspective, Top, Bottom, Front, Back, Left, Right Numpad 5, 7, 1, 3 (with Ctrl: the opposite) The point of view of the active view.
Normal, Polygons, Wireframe Z The rendering of the active view.
Four views Q One view or four.
Frame selection F Brings the views close to the selection; with nothing selected, shows the whole scene.
Show the whole scene Home Brings the views back to the whole scene, seen from a little above.
Show everything again Shows again the objects hidden with the eye of the list.
Grid Shows or hides the grid.
Walkable areas Shows where characters can walk: blue, what they reach from the player; orange, isolated spots. See character walking.
Left panel, Right panel, Library, Console Shows or hides each area.

Game¶

Command Shortcut Effect
Play F5 Starts the game in its window.
Stop F5 Closes the game.
Creation assistant... Reopens the assistant that prepares a request for the agent (in a project).

Agent¶

Command Effect
Conversation Opens the Agent panel on the conversation.
New conversation Starts again from an empty conversation.
Agent settings Opens the settings: account, model, reasoning effort, rules. See The agent.

Help¶

  • Keyboard shortcuts: the list of shortcuts below.
  • Licenses: the licenses of the open-source software inside WorldMint and your games. The same file, THIRD_PARTY_NOTICES.txt, sits next to the editor, and the export puts it in every game: nothing to do on your side.
  • Language: Français or English. The interface changes at once.

Keys Effect

Ctrl + numpad 7, 1, 3 Bottom, back, left view

F2 Rename the selected object

Single-key shortcuts do nothing while you type in a field.

Dialog boxes¶

  • Save your changes?: before opening another scene, creating one or quitting, if the scene has changes. Save, Don't save, or Keep working (nothing happens).
  • Recover your work?: at launch, if the editor closed without saving and an automatic backup holds your work. Recover reopens it (then save to keep it); Don't recover discards it. "The scene file stays unchanged until you save."
