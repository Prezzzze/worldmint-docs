The Trigger: "when… then…"¶

The Trigger system makes the game react without writing code. You place rules on an object that read like a sentence: when the player steps on this plate, then the door opens. They are all set in the object's Properties, and the agent can place them for you.

Every field is detailed in the Trigger reference.

Placing a rule¶

  1. Activate the system: Game tab, Systems section, Activate under Trigger (see The Game tab).
  2. Place it on the object the rule is about (the plate, the lever, the boss): drag Trigger from the library's Systems folder onto the object, or, in its Properties, Systems section, click + System.
  3. In the object's Properties, under Trigger, click Add: Rule. A Rule 1 appears, in its own frame; the cross on its right removes it. An object can carry as many rules as needed.
  4. Choose When, then Then, then fill in the fields that appear: only those useful for the chosen action are shown.

Every change goes through the history: Ctrl+Z undoes it.

When¶

When What the object needs
Someone enters this zone (Zone system) The Zone system: see Physics and zones.
Someone leaves this zone (Zone system) The Zone system.
The player uses it (Interaction system) The Interaction system: the player walks up to it and presses its key (E at first).
It dies (Health system) The Health system.
When the game starts Nothing.
After a time Nothing: you give the number of seconds of play.
When an event happens Nothing: you give the event's name, one of a system (see The events) or a name chosen for this game.
Its joint breaks (Joint system) The Joint system, with a breaking force or the Break action.

How many times: Only once, or Every time. With After a time and Every time, the action comes back every so many seconds.

Wait before acting (seconds): a delay between the moment the rule fires and the action. A door that closes three seconds after the player went through.

Then¶

Then What it does
Show an object, Hide an object A hidden object can no longer be seen and no longer stops anyone: a hidden door is an open door.
Show or hide, in turn Each time, the opposite of the time before: a lever that opens, then closes.
Switch a light on, Switch a light off, Switch a light on or off, in turn A placed light: a lever that lights a lamp.
Change a light's color It takes the New color of the light: an alarm turning red.
Destroy an object Removes it from the game (never the player).
Make a copy appear Copies the chosen object, at the place chosen in Where it appears. The copied object is usually a hidden model, kept aside.
Teleport the player to an object The player ends up where that object is.
Make solid, Make passable A passable object stays visible but no longer stops anyone. On a zone: switches it back on, or off.
Go to another scene The player goes to the chosen Scene, at its Arrival point.
End the game Victory or Defeat, with a Text to show; the game offers to play again.
Play a sound A sound from the library, played where the object is.
Play a video A video from the library, full screen, with its sound; the world stops meanwhile. The player can skip it or not; Event sent at the end chains what comes next. See Videos.
Play an effect (fire, chips, explosion…), Stop an effect Lights again the effect the target carries (its Particle effect system: a brazier lit by a lever), or plays a ready-made effect on it, once, at the chosen Size of the effect; Stop an effect puts it out. See Particles and decals.
Muffle the sound (under water, behind a wall) Muffles a group of the sound mixer, or all the game's sound, from 0 (clear again) to 1 (under water), over a few seconds.
Mute or unmute a group of sounds Silences a group of the sound mixer (the ambience during a story scene), or brings it back.
Show a message A text on screen, for the Message duration.
Push a moving object (Physics system) Throws an object that carries the Physics system, away from the player and upwards: a kick in a ball.
Send an event Announces an event, which another rule (When an event happens) or a script can listen to.
Open (a door, a drawbridge: Joint system), Close (Joint system) The joint's motor brings it to its open or closed stop: see Vehicles, joints and ragdolls.
Break its joint: it falls The joint gives way, even an unbreakable one.
Make it fall limp (ragdoll), Get it back up (ragdoll) An animated character falls like a rag doll, or gets back up.

On which object: a list of the scene's objects, with a search. Left at This object, the action targets the object carrying the rule.

Three examples¶

A plate that opens a door¶

  1. Object > Create > Zone: a box invisible in the game, which carries the Zone system. Rename it "Plate" (F2), place it in front of the door and set its Scale, for example 2 × 0.2 × 2.
  2. Place the Trigger on the plate, then Add: Rule:
    • When: Someone enters this zone (Zone system);
    • Then: Hide an object;
    • On which object: the door.

For the door to close again when the player steps off, add a second rule: Someone leaves this zone, Every time, Show an object, the door. Set the first one to Every time as well.

A lever¶

  1. Place the Interaction system on the lever. In its settings, Prompt text can say "Lever": the player sees "E: Lever" when walking up to it.
  2. Place the Trigger on the lever, with one rule:
    • When: The player uses it (Interaction system);
    • How many times: Every time;
    • Then: Show or hide, in turn;
    • On which object: the door, or the gate.

A defeated boss wins the game¶

The boss carries the Health system (like the enemies of the Enemies system). Place the Trigger on it:

  • When: It dies (Health system);
  • Then: End the game;
  • Result: Victory;
  • Text to show: "The dragon is defeated!".

For a sequel rather than an ending: Then: Show an object, a hidden chest near the boss; or Go to another scene.

Reusable actions¶

When no ready-made action fits (a door that slides aside, a bridge that rises, a light that blinks), ask the agent for it. It writes it once, as a reusable action: it is then added to the Then list of every Trigger in the game, under Written for this game, next to the ready-made actions.

For example, in the Agent panel:

Make me a reusable action "Sliding door": the target slides aside, by a distance I can set.

Then:

  • In a rule, Then offers Sliding door; hovering it shows its description.
  • Its settings (here, the distance) appear under the rule, like those of the ready-made actions, and change rule by rule.
  • You reuse it on other objects, without asking the agent again.

The action is a game script, visible in the Scripts tab under the name action. followed by its identifier (action.porte_glissante). If that script is deleted, the rule that used it says so: "The action “porte_glissante” no longer exists in this game: nothing will happen."

As long as no action has been written for this game, the Then list reminds you: "For an action that does not exist yet, ask the agent for it: it will be added to this list."

Asking the agent¶

The agent knows the Trigger and prefers it to a script for these reactions, so that you keep control of the rules. A few requests:

  • "When the player steps on the plate, open the dungeon door."
  • "The lever opens and closes the gate."
  • "When the boss dies, the game is won."
  • "Every 30 seconds, make an enemy appear near the tower."

The rules it places then show in the object's Properties: you can read them and change them.
