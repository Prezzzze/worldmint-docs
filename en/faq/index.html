Frequently asked questions¶

The editor¶

I made a mistake. How do I go back? Ctrl+Z, as many times as needed; Ctrl+Y redoes. This also applies to what the agent did. Under each answer of the agent, Undo these changes undoes its whole turn at once.

The editor closed before I saved. Have I lost everything? No. An automatic backup keeps a copy of your work every 60 seconds. On the next launch, the editor offers Recover your work?: click Recover, then save (Ctrl+S).

Where are my files? In the project folder: File > Open project folder. The first project is in Documents\WorldMint\Mon premier jeu. See Projects and scenes.

An object disappeared from the view. It may be hidden by the eye of the scene list: View > Show everything again. Or it is elsewhere: select it in the list, then F to frame the view on it.

My model does not appear in the library. The editor reads .glb, .gltf, .fbx and .obj files. COLLADA files (.dae) are counted as "Not read (COLLADA)". Also check that its folder was added (Add a folder).

My model is tiny or gigantic. Change its Scale in the properties. The sizes that trigger a warning are set in the game's settings, Technical settings section.

How do I switch the editor to French? Help > Language > Français, or the Preferences.

The text is too small. Preferences > Interface size.

The game¶

The Play button does nothing. The game needs a player: the console says "No player: select an object, then choose "Set as player"." Select a character and click Set as player.

The player falls through the ground. The ground needs a Collision (Appearance section of its properties), or must be a terrain.

The player appears anywhere when arriving in a scene. The scene has no arrival point, or the passage does not name one: see Linking scenes.

How do I get the mouse out of the game window? Esc frees it (unless the game uses Esc for its own pause).

The game crashed. The editor and your scene are safe: the console says "The game crashed (code ...)". Start again with F5.

How do I change the game's keys? Game tab, Controls section: see Game controls.

How do I give my game to someone? File > Export game...: see Exporting a game. Send the whole exported folder.

The agent¶

Do I have to pay to use the agent? The agent works with your own account: a Claude subscription (Pro, Max, Team or Enterprise), a usage-billed account (Anthropic Console, API key), or for Codex a ChatGPT account or an OpenAI API key. That account counts the agent's usage, under its own terms; under each answer, the editor shows the cost when the account is billed by usage.

Can the agent touch my files or my computer? No. It only has the editor's tools, which act on the open project: see What the agent does. An agent that arrives with other tools is stopped before it does anything.

The agent no longer answers. The panel says so after a while without news. It may still be working; the square button stops it. You can then write to it again: the conversation goes on.

Can it see what I see? It can look at the scene as an image by itself. You can also attach A capture of the 3D view, an image or a PDF (paperclip of the input area).

Can it use my models? Yes, all those in the library. If a folder is not there yet, write its path in your message: it is added.

How do I change the way it works? Agent settings > Agent rules > Customize for this project creates an AGENT.md file in the project, which you can edit. Or simply tell it: your request comes before its rules.

Which model should I choose? Default is fine. A higher reasoning effort gives more thought-out answers, but slower ones.
